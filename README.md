# CalculeTonOrga 

Le but de l'application, c'est de pouvoir avoir des statistiques de sa vie, d'avoir des données sur les lieux dans lequel on va et le temps qu'on passe à faire chaque activité.

## Pour commencer

1. Installer les dépendances

   ```bash
   npm install
   ```

2. Démarrer l'application

   ```bash
   npx expo start
   ```

Ensuite, vous n'avez plus qu'à scanner le qrcode ou l'url proposée. Attention! Il faut être sur le même réseau pour pouvoir accéder à l'application :)
